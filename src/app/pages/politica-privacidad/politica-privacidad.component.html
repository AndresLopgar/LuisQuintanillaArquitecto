2. ¿Qué datos se recogen?

4. Base jurídica

Cuando realizas una consulta o solicitas presupuesto, el tratamiento resulta necesario para atender las medidas precontractuales solicitadas por ti. Si posteriormente se formaliza un encargo profesional, los datos se tratarán para ejecutar dicho encargo y para cumplir las obligaciones legales y profesionales correspondientes.

5. Conservación

Los datos se conservarán durante el tiempo necesario para atender la consulta y, cuando exista un encargo profesional, durante la relación profesional y los plazos posteriores exigidos por la legislación aplicable o necesarios para atender posibles responsabilidades.

6. Destinatarios

Los datos no se cederán a terceros salvo obligación legal o cuando resulte necesario para desarrollar un encargo expresamente solicitado, por ejemplo ante Administraciones Públicas, Ayuntamientos, Catastro, colegios profesionales u otros organismos competentes.
